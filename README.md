# Проверка изоморфизма гиперграфов отношений

Реализация алгоритма проверки изоморфизма гиперграфов отношений
для случая коммутативных гиперрёбер фиксированной арности.
Алгоритм из статьи: T. Kosovskaya, "On the isomorphism of hypergraphs of relations".

## Запуск

python3 hypergraph_isomorphism.py

При запуске можно выбрать режим `demo` — воспроизводится пример из статьи —
или ввести гиперграфы вручную.
